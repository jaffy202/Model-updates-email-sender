
Model: Mercury 3
Lead: Mercury 3 is a language model from Inception, released in October 2026, with a 1M-token context window, and pricing from $0.100/M input, $0.010/M cached input, $0.350/M output.
Description: Mercury 3 is Inception's flagship diffusion-based LLM (dLLM), released 2026-10-19 and described as the most capable diffusion LLM released to date. Inception says it is more than 40x larger in total parameters than Mercury 1 and runs at about 1,068 output tokens per second on NVIDIA GPUs while matching or beating speed-optimized models such as GPT-6 Luna and Claude Haiku 5.5. It has a 1M-token context window, up to 131,072 output tokens, tunable reasoning effort (instant, low, medium, high), tool calling, and structured outputs. Text in, text out. Available on the Inception API, OpenRouter, Vercel AI Gateway, and Baseten.

Model: MiniMax M3.1 Flash
Lead: MiniMax M3.1 Flash is a language model from MiniMax, released in October 2026, with multimodal input, a 1M-token context window, and pricing from $0.150/M input, $0.015/M cached input, $0.600/M output.
Description: MiniMax M3.1 Flash is the flash successor in the MiniMax M3 family, released 2026-10-19. Thinking is always on (cannot be disabled) with effort levels low/medium/high/xhigh/max (default max). Available via the MiniMax API (Anthropic-compatible and OpenAI-compatible endpoints), M Plan, and MiniMax Code.

Model: Beam 1.0
Lead: Beam 1.0 is a language model from Reflection AI, released in October 2026, with a 1.0M-token context window, and pricing from $0.400/M input, $0.040/M cached input, $1.20/M output.
Description: Beam 1.0 is Reflection AI's first open-weight model: a sparse Mixture-of-Experts reasoning model with 501.3B total parameters and 23.4B active per token (52 layers: 3 dense + 49 MoE; 256 experts; gated GQA with sliding-window attention; 152K vocabulary), pretrained on 23.8T tokens and post-trained with large-scale asynchronous RL. It targets coding, long-horizon agentic work, and tool use, with a 1M-token context window, up to 128K output tokens on the Reflection API, text-only input/output, and mandatory reasoning with low/medium/high/xhigh/max effort levels. Released under Apache 2.0 in BF16, FP8, and NVFP4 with a DFlash speculative-decoding drafter; available on Hugging Face, the Reflection API (Beam-1.0-501B-A23B), OpenRouter, and other partners.

Model: Nemotron Labs Dory 1.0 (4B)
Lead: Nemotron Labs Dory 1.0 (4B) is a language model from Nvidia, released in October 2026.
Description: NVIDIA Nemotron Labs Dory 1.0 4B is an open-weight looped (latent-recurrent) normalized-GPT language model with interleaved sliding-window attention (SWA) and full-attention layers. A shared recurrent block can be applied multiple times at inference (recommended default: 2 loops) to trade compute for accuracy without swapping checkpoints. Text-in / text-out, English, up to 256K context (max_position_embeddings 262144). Reasoning model with tool calling. Pre-trained on 6T tokens (NVFP4 then BF16) plus 300B context-extension tokens; training data collected through December 2025. Released under OpenMDW License Agreement v1.1. Weights: BF16 (siblings MXFP8, NVFP4, GGUF).

Model: Muse Spark Open
Lead: Muse Spark Open is a language model from Meta, released in October 2026, with multimodal input, a 1.0M-token context window, and pricing from $1.25/M input, $0.150/M cached input, $4.25/M output.
Description: Muse Spark Open is Meta Superintelligence Labs' open-weight natively multimodal Mixture-of-Experts model (816B total / 42B active parameters) with a 1,048,576-token context window. The HF model card specifies text, image, video, and audio inputs and text output. It supports configurable reasoning_effort (low/medium/high/xhigh; default xhigh) and is positioned for coding and agentic workflows. Weights are released under the Muse Model License with limited commercial terms and are available on Hugging Face as meta-models/Muse-Spark-Open-816B-A42B (BF16) and an NVFP4 sibling. Hosted inference is offered by third-party providers including Together AI, Fireworks AI, Groq, Modal, Nebius, Baseten, and OpenRouter (slug meta/muse-spark-open).

Model: Nemotron 3.5 Bolt (74B A9B 24GB)
Lead: Nemotron 3.5 Bolt (74B A9B 24GB) is a language model from Nvidia, released in October 2026, with multimodal input.
Description: NVIDIA Nemotron 3.5 Bolt is an open multimodal 74B total / 9B active Mixture-of-Experts vision-language model for local / edge agentic workloads. Compressed from Nemotron 3.5 Super VL into a native IQ2 (2-bit) 24GB footprint for RTX / DGX Spark and similar systems, with a hybrid Mamba-2 + LatentMoE + Attention backbone and C-RADIO v4-H vision encoder. Accepts text, image, and video inputs and produces text; up to 256K context; tool use and configurable reasoning. A full-precision BF16 sibling is published at nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-BF16. Released under OpenMDW-1.1.
