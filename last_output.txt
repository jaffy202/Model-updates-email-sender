
Model: Gemini 4 Carbon
Lead: Gemini 4 Carbon is a language model from Google, released in October 2026, with multimodal input.
Description: Gemini 4 Carbon is Google DeepMind's next frontier model, announced on 2026-10-28, which Google describes as "our strongest model with state-of-the-art cybersecurity and long horizon capabilities." It builds on Gemini 4 Argon, with gains in vulnerability finding, exploit validation, patching, and long-horizon agentic coding. At announcement it is in a limited rollout: available only to a subset of cyber defenders and, in phases, to trusted partners through Google's Fairwind Program, with availability to developers, businesses, and consumers planned later. Google states it will launch at the same introductory price as Argon ($2.00 per million input tokens, $10.00 per million output tokens, cached input 95% off), moving to $4.00/$20.00 after the introductory period. There is no public API endpoint yet.

Model: Particle-1
Lead: Particle-1 is a language model from Particle AI, released in October 2026, with multimodal input, a 1.0M-token context window, and pricing from $0.250/M input, $0.030/M cached input, $1.00/M output.
Description: Particle-1 is Particle AI's first model, a reinforcement-learning post-train of DeepSeek V4.1 Flash (rank-64 LoRA over the experts in all layers, trained with GSPO in Cascade RL stages on internal coding and data-engineering environments). It targets agentic software engineering and is tuned to solve tasks with fewer tokens: Particle reports 28.4% to 52.2% fewer output tokens and 34.4% to 51.6% lower cost per task than the base model on Terminal-Bench 2.1, ReactBench, ADE Bench, and DeepSWE 1.1, with pass@1 within the base model's confidence intervals (72.57% aggregate task pass rate vs 71.15% for DeepSeek V4.1 Flash). Text and image input, text output, reasoning with effort control, OpenAI-compatible tool calling, 1,048,576-token context and 131,072 max output tokens. Weights are not released; it is available through the Particle API and OpenRouter (particle-ai/particle-1) at $0.25 input, $0.03 cached input, and $1.00 output per million tokens (peak; off-peak 50% off, 20:30 to 04:00 America/New_York).

Model: GPT-6.1 Terra
Lead: GPT-6.1 Terra is a language model from OpenAI, released in October 2026, with multimodal input, a 1.1M-token context window, and pricing from $1.00/M input, $0.050/M cached input, $5.00/M output.
Description: GPT-6.1 Terra is OpenAI's fast, efficient GPT-6.1 model for visual reasoning, precise computer use, and clear, natural writing, priced 50% below GPT-5.6 Terra and GPT-6.1 Sol. The API model id is gpt-6.1-terra. It accepts text and image input with text output, supports none, low, medium (API default), high, xhigh, and max reasoning effort, and provides a 1,050,000-token context window with up to 128,000 output tokens. Use the Responses API for tool calling; Chat Completions is supported without tool calling. Responses API tools include web and file search, image generation, code interpreter, hosted shell, apply patch, skills, computer use, MCP, and tool search; it also supports streaming, function calling, and structured outputs. Standard per-million-token pricing is $1 input, $0.05 cached input, $1.25 cache writes (30-minute retention rate; 12-hour retention is $2.50), and $5 output. Prompts above 272K input tokens cost 2x input/cache and 1.5x output across the full request. Batch and Flex cost 50% of Standard; Fast costs 2x. Regional processing adds 10% where available. Launch benchmarks are OpenAI-reported; effort and evaluation variants are recorded with each score.

Model: Kimi K3.1 Pro
Lead: Kimi K3.1 Pro is a language model from MoonshotAI, released in October 2026, with multimodal input, a 1.0M-token context window, and pricing from $2.00/M input, $0.200/M cached input, $10.00/M output.
Description: Kimi K3.1 Pro is the first model in Moonshot AI's K3.1 series, a post-trained version of Kimi K3 built with substantially larger post-training compute and large-scale joint reinforcement learning across hundreds of domains. Moonshot describes it as its most capable 3T-class open-weight model, with a 1,048,576-token context window, text/image/video input, tool calling, structured output, and always-on reasoning (low, high, or max; Moonshot API default max). max_completion_tokens defaults to 131,072 and can be raised to 1,048,576. It targets long-horizon coding, 3D creation and CAD, financial research, and other agentic work. Pricing is a one-third cut from K3 ($2 / $10 vs $3 / $15 per MTok). A Highspeed variant (kimi-k3.1-pro-highspeed) offers 2-3x the speed with the same capabilities at $4 / $20 (cached input $0.20). Full weights are scheduled for release by Nov 4, 2026.

Model: Mercury 3
Lead: Mercury 3 is a language model from Inception, released in October 2026, with a 1M-token context window, and pricing from $0.100/M input, $0.010/M cached input, $0.350/M output.
Description: Mercury 3 is Inception's flagship diffusion-based LLM (dLLM), released 2026-10-19 and described as the most capable diffusion LLM released to date. Inception says it is more than 40x larger in total parameters than Mercury 1 and runs at about 1,068 output tokens per second on NVIDIA GPUs while matching or beating speed-optimized models such as GPT-6 Luna and Claude Haiku 5.5. It has a 1M-token context window, up to 131,072 output tokens, tunable reasoning effort (instant, low, medium, high), tool calling, and structured outputs. Text in, text out. Available on the Inception API, OpenRouter, Vercel AI Gateway, and Baseten.

Model: MiniMax M3.1 Flash

Description: MiniMax M3.1 Flash is the flash successor in the MiniMax M3 family, released 2026-10-19. Model: Beam 1.0
Lead: Beam 1.0 is a language model from Reflection AI, released in October 2026, with a 1.0M-token context window, and pricing from $0.400/M input, $0.040/M cached input, $1.20/M output.
Description: Beam 1.0 is Reflection AI's first open-weight model: a sparse Mixture-of-Experts reasoning model with 501.3B total parameters and 23.4B active per token (52 layers: 3 dense + 49 MoE; 256 experts; gated GQA with sliding-window attention; 152K vocabulary), pretrained on 23.8T tokens and post-trained with large-scale asynchronous RL. It targets coding, long-horizon agentic work, and tool use, with a 1M-token context window, up to 128K output tokens on the Reflection API, text-only input/output, and mandatory reasoning with low/medium/high/xhigh/max effort levels. Released under Apache 2.0 in BF16, FP8, and NVFP4 with a DFlash speculative-decoding drafter; available on Hugging Face, the Reflection API (Beam-1.0-501B-A23B), OpenRouter, and other partners.
