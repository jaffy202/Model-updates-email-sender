
Model: Gemini 4 Neon
Lead: Gemini 4 Neon is a language model from Google, released in November 2026, with multimodal input, a 1.0M-token context window, and pricing from $3.00/M input, $0.150/M cached input, $15.00/M output.
Description: Gemini 4 Neon is Google DeepMind's fast Gemini 4 reasoning model for complex software engineering, knowledge work, and science workflows, generally available on the Gemini API paid tier on 2026-11-18 (model id gemini-4-neon). Google positions it between Gemini 4 Hydrogen and Gemini 4 Carbon. It is not available on the free tier. It uses a 1,048,576-token unified context window with up to 64K default synchronous output tokens and long decode up to 1M tokens, accepts text, image, video, audio, and PDF input with text output, and supports four thinking levels: low, medium, high (default), and xhigh. Gemini API paid pricing is flat across the 1M window at $3.00 per million input tokens, $15.00 per million output tokens (including thinking tokens), and $0.15 per million implicitly cached input tokens; explicit caching is not supported. Vertex AI global endpoints use the same $3.00 / $15.00 / $0.15 rates; non-global endpoints are billed at a 10% premium. The knowledge cutoff is March 2026. Google had not published official benchmark results as of 2026-11-18.

Model: GPT-6.2 Astra
Lead: GPT-6.2 Astra is a language model from OpenAI, released in November 2026, with multimodal input, a 1.1M-token context window, and pricing from $8.00/M input, $0.400/M cached input, $40.00/M output.
Description: GPT-6.2 Astra is OpenAI's frontier GPT-6.2 model for the hardest end-to-end professional work, including complex coding, computer use, scientific work, and creating slides, spreadsheets, and documents. The API model id is gpt-6.2-astra. It accepts text and image input with text output, supports low, medium, high, xhigh, and max reasoning effort (but not none), and provides a 1,050,000-token context window (922,000 max input) with up to 128,000 output tokens. Responses API tools include web and file search, image generation, code interpreter, hosted shell, apply patch, skills, computer use, MCP, and tool search; it also supports streaming, function calling, structured outputs, and multi-agent delegation (beta). Standard per-million-token pricing is $8 input, $0.40 cached input, $10 cache writes (30-minute retention), and $40 output, 20% below GPT-6 Astra on input and output, with cached input 60% below GPT-6 Astra ($0.40 vs $1.00). Prompts above 272K input tokens cost 2x input/cache and 1.5x output across the full request. Batch costs 50% of Standard; Fast costs 2x; Ultrafast costs 3 times the Standard rate through February 28, 2027, and 6 times the Standard rate starting March 1, 2027 (Pacific time). Launch benchmarks are OpenAI-reported; effort variants are recorded with each score.

Model: Hy4 flash
Lead: Hy4 flash is a language model from Tencent, released in November 2026, with multimodal input, a 960K-token context window, and pricing from $0.070/M input, $0.003/M cached input, $0.281/M output.
Description: Hy4 flash is Tencent Hy's most cost-effective Hy model, announced on 2026-11-16 (API id hy4-flash). It has 224 billion total parameters, including 64 billion Engram parameters, with 12 billion active parameters per token. Like Hy4, it is natively multimodal and has a 1,048,576-token context window (Tencent Cloud TokenHub documents 960K max input and 64K max output). Official TokenHub USD list pricing, from Tencent Cloud documentation https://www.tencentcloud.com/document/product/1300/78937, is $0.070 per million input tokens, $0.281 per million output tokens, and $0.003 per million cached input tokens. That same pricing notice offers 50% off Hy4 flash list API pricing until 12:00 Beijing time on 2026-11-30 (11:00 PM ET on 2026-11-29). The official research page also says WorkBuddy access is free until 30 November. Tencent says Hy4 flash will launch on OpenRouter soon and that it plans to open-source the model; no release date was given for the weights, and neither the OpenRouter listing nor the weights were published at catalog time. Tencent's evaluation emphasizes its internal WorkIndex benchmark and a WorkBuddy blind test, and the launch page also reports self-reported scores on public agent and multimodal benchmarks in an official appendix, evaluated at the highest available reasoning setting.

Model: Qwen4-Max
Lead: Qwen4-Max is a language model from Qwen, released in November 2026, with multimodal input, a 984K-token context window, and pricing from $1.50/M input, $0.075/M cached input, $4.50/M output.
Description: Qwen4-Max is Alibaba's next-generation flagship multimodal model in the Qwen family, generally available on 2026-11-16 (model id qwen4-max). It is a sparse mixture-of-experts model with 2.4 trillion backbone parameters, 71 billion active parameters per token, and an additional 328 billion N-gram Embedding parameters, with native text, image, and video understanding, a 1,000,000-token context window, and thinking enabled by default (reasoning_effort levels low, high, and xhigh; default high; thinking_budget default 131,072; maximum thinking plus final answer 262,144 tokens; maximum input 983,616 tokens in thinking mode and 991,808 in non-thinking mode). It supports function calling, web search, structured outputs, explicit and implicit cache, and the OpenAI Chat Completions and Responses APIs and the Anthropic Messages API. QwenCloud Singapore list pricing is $1.50 per million input tokens and $4.50 per million output tokens, with cache write $1.875 (5-minute TTL) or $3 (1-hour TTL) and cache read $0.075 per million tokens. Beijing and Global regions list $1.413 input and $4.24 output, with cache write $1.767 (5-minute TTL) or $2.827 (1-hour TTL) and cache read $0.071 per million tokens. This card is the generally available model; the earlier Token Plan-only preview is cataloged separately as qwen4-max-preview. The official Qwen team launch post says smaller models in the Qwen4 family are coming to open source; no open weights for Qwen4-Max were published at catalog time.

Model: ERNIE 5.5 Flash Preview
Lead: ERNIE 5.5 Flash Preview is a language model from Baidu, released in November 2026, with a 1.0M-token context window, and pricing from $0.280/M input, $0.028/M cached input, $1.13/M output.
Description: ERNIE 5.5 Flash Preview is Baidu's first post-trained model built on ERNIE 5.5 Flash Base. It is a mixture-of-experts model with 280 billion total parameters and 14 billion active parameters, a 1,048,576-token context window, and text-only input and output. Baidu describes it as strong at coding, 3D modeling, knowledge work, and content creation, and as an intermediate post-training checkpoint: some capabilities may still fall short, and an official (non-preview) release is planned. The API is available on the Qianfan platform as ernie-5.5-flash-preview. Baidu says the weights will be open-sourced under Apache 2.0. Qianfan international pay-as-you-go pricing is $0.28 per million input tokens, $0.028 per million cache-hit tokens, and $1.13 per million output tokens. On Qianfan, thinking cannot be disabled, and reasoning effort cannot be adjusted (the documented default is high).

Model: Qwen4-Max-Preview
Lead: Qwen4-Max-Preview is a language model from Qwen, released in November 2026, with multimodal input.
Description: Qwen4-Max-Preview is the next-generation flagship multimodal model in the Qwen family, combining text generation, image and video understanding, and deep reasoning for coding, office productivity, frontend design, and complex agentic tasks. The model id is qwen4-max-preview. It has a 1,000,000-token context window and a maximum output of 393,216 tokens, shared by thinking and the final answer. Thinking is enabled by default, with reasoning_effort levels low, medium, and xhigh (default xhigh). It supports function calling, web search, built-in tools, and structured outputs, and is compatible with the OpenAI Chat Completions and Responses APIs and the Anthropic Messages API. The preview is available through Alibaba's Token Plan only; pay-as-you-go access is not supported. The preview runs from 10:00 on 2026-11-11 to 24:00 on 2026-11-25 (UTC+8) and will be retired when the preview ends.
