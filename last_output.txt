
Model: Hy4 flash
Lead: Hy4 flash is a language model from Tencent, released in November 2026, with multimodal input, a 960K-token context window, and pricing from $0.070/M input, $0.003/M cached input, $0.281/M output.
Description: Hy4 flash is Tencent Hy's most cost-effective Hy model, announced on 2026-11-16 (API id hy4-flash). It has 224 billion total parameters, including 64 billion Engram parameters, with 12 billion active parameters per token. Like Hy4, it is natively multimodal and has a 1,048,576-token context window (Tencent Cloud TokenHub documents 960K max input and 64K max output). Official TokenHub USD list pricing, from Tencent Cloud documentation https://www.tencentcloud.com/document/product/1300/78937, is $0.070 per million input tokens, $0.281 per million output tokens, and $0.003 per million cached input tokens. That same pricing notice offers 50% off Hy4 flash list API pricing until 12:00 Beijing time on 2026-11-30 (11:00 PM ET on 2026-11-29). The official research page also says WorkBuddy access is free until 30 November. Tencent says Hy4 flash will launch on OpenRouter soon and that it plans to open-source the model; no release date was given for the weights, and neither the OpenRouter listing nor the weights were published at catalog time. Tencent's evaluation emphasizes its internal WorkIndex benchmark and a WorkBuddy blind test, and the launch page also reports self-reported scores on public agent and multimodal benchmarks in an official appendix, evaluated at the highest available reasoning setting.

Model: Qwen4-Max
Lead: Qwen4-Max is a language model from Qwen, released in November 2026, with multimodal input, a 984K-token context window, and pricing from $1.50/M input, $0.075/M cached input, $4.50/M output.
Description: Qwen4-Max is Alibaba's next-generation flagship multimodal model in the Qwen family, generally available on 2026-11-16 (model id qwen4-max). It is a sparse mixture-of-experts model with 2.4 trillion backbone parameters, 71 billion active parameters per token, and an additional 328 billion N-gram Embedding parameters, with native text, image, and video understanding, a 1,000,000-token context window, and thinking enabled by default (reasoning_effort levels low, high, and xhigh; default high; thinking_budget default 131,072; maximum thinking plus final answer 262,144 tokens; maximum input 983,616 tokens in thinking mode and 991,808 in non-thinking mode). It supports function calling, web search, structured outputs, explicit and implicit cache, and the OpenAI Chat Completions and Responses APIs and the Anthropic Messages API. QwenCloud Singapore list pricing is $1.50 per million input tokens and $4.50 per million output tokens, with cache write $1.875 (5-minute TTL) or $3 (1-hour TTL) and cache read $0.075 per million tokens. Beijing and Global regions list $1.413 input and $4.24 output, with cache write $1.767 (5-minute TTL) or $2.827 (1-hour TTL) and cache read $0.071 per million tokens. This card is the generally available model; the earlier Token Plan-only preview is cataloged separately as qwen4-max-preview. The official Qwen team launch post says smaller models in the Qwen4 family are coming to open source; no open weights for Qwen4-Max were published at catalog time.

Model: Gemini 4 Hydrogen
Lead: Gemini 4 Hydrogen is a language model from Google, released in November 2026, with multimodal input, a 1.0M-token context window, and pricing from $1.50/M input, $0.075/M cached input, $7.50/M output.
Description: Gemini 4 Hydrogen is Google DeepMind's Gemini 4 model for everyday coding and agentic workflows, announced and generally available on 2026-11-12 (model id gemini-4-hydrogen). It is adapted from Gemini 4 Carbon and is available on the Gemini API free and paid tiers, Google AI Studio, Vertex AI, the Gemini app, Google Search, and Google Antigravity. It uses a 1,048,576-token unified context window with up to 64K default synchronous output tokens and long decode up to 1M tokens, and adds a fourth thinking level, xhigh, alongside low, medium, and high (default high). Gemini API paid pricing is flat across the 1M window at $1.50 per million input tokens, $7.50 per million output tokens (including thinking tokens), and $0.075 per million implicitly cached input tokens; explicit caching is not supported. Vertex AI global endpoints use the same $1.50 / $7.50 / $0.075 rates; non-global endpoints are billed at a 10% premium. The knowledge cutoff is March 2026.

Model: ERNIE 5.5 Flash Preview
Lead: ERNIE 5.5 Flash Preview is a language model from Baidu, released in November 2026, with a 1.0M-token context window, and pricing from $0.280/M input, $0.028/M cached input, $1.13/M output.
Description: ERNIE 5.5 Flash Preview is Baidu's first post-trained model built on ERNIE 5.5 Flash Base. It is a mixture-of-experts model with 280 billion total parameters and 14 billion active parameters, a 1,048,576-token context window, and text-only input and output. Baidu describes it as strong at coding, 3D modeling, knowledge work, and content creation, and as an intermediate post-training checkpoint: some capabilities may still fall short, and an official (non-preview) release is planned. The API is available on the Qianfan platform as ernie-5.5-flash-preview. Baidu says the weights will be open-sourced under Apache 2.0. Qianfan international pay-as-you-go pricing is $0.28 per million input tokens, $0.028 per million cache-hit tokens, and $1.13 per million output tokens. On Qianfan, thinking cannot be disabled, and reasoning effort cannot be adjusted (the documented default is high).

Model: Qwen4-Max-Preview
Lead: Qwen4-Max-Preview is a language model from Qwen, released in November 2026, with multimodal input.
Description: Qwen4-Max-Preview is the next-generation flagship multimodal model in the Qwen family, combining text generation, image and video understanding, and deep reasoning for coding, office productivity, frontend design, and complex agentic tasks. The model id is qwen4-max-preview. It has a 1,000,000-token context window and a maximum output of 393,216 tokens, shared by thinking and the final answer. It supports function calling, web search, built-in tools, and structured outputs, and is compatible with the OpenAI Chat Completions and Responses APIs and the Anthropic Messages API. The preview is available through Alibaba's Token Plan only; pay-as-you-go access is not supported. The preview runs from 10:00 on 2026-11-11 to 24:00 on 2026-11-25 (UTC+8) and will be retired when the preview ends.

Model: Claude Fable 5.2
Lead: Claude Fable 5.2 is a language model from Anthropic, released in November 2026, with multimodal input, a 1M-token context window, and pricing from $8.00/M input, $0.200/M cached input, $40.00/M output.
Description: Claude Fable 5.2 is Anthropic's generally available, safeguarded deployment of the same underlying model as Claude Mythos 5.2 (verification-program access only). It targets demanding reasoning and long-horizon agentic work with text and image input, text output, tool use, multilingual and vision support, and adaptive thinking that is always on (Claude API default effort high). Context window is 1M tokens with 128K max output on the sync Messages API; reliable knowledge and training-data cutoffs are June 2026. First-party pricing drops to $8/$40 per million input/output tokens (from $10/$50 on Fable 5.1), with cache reads at $0.20 (0.025x base input), 5-minute cache writes at $10 and 1-hour cache writes at $16 per million tokens; Batch is 50% off. Optional fast mode gives up to 2.5x higher output tokens per second at $16/$80 per million input/output tokens and is not available with the Batch API. Anthropic reports outputs up to 30% faster than Fable 5.1 and, in early testing across claude.ai, Claude Code and Cowork, about 55% fewer cyber and bio safeguard blocks than Fable 5.1. Self-reported launch scores with safeguards enabled include FrontierCode 2.0 49.1% (xhigh), FrontierSWE v2 69.9%, SWE-bench Pro 93.0%, Terminal-Bench 4.0 67.6%, Humanity's Last Exam 74.2% with tools, OSWorld 2.1 offline set 89.3% partial, and AutomationBench 51.4%. Available as `claude-fable-5-2` on the Claude API, Amazon Bedrock (`anthropic.claude-fable-5-2`), Claude Platform on AWS, Claude Models on Google Cloud and Microsoft Foundry.

Model: Claude Mythos 5.2
Lead: Claude Mythos 5.2 is a language model from Anthropic, released in November 2026, with multimodal input, a 1M-token context window, and pricing from $8.00/M input, $0.200/M cached input, $40.00/M output.
Description: Claude Mythos 5.2 is Anthropic's verification-only deployment of the same underlying model as Claude Fable 5.2, with more permissive safeguards in biology and cybersecurity, the high-risk dual-use domains where Fable carries additional safeguards. Access is limited to organizations verified through Anthropic's Cyber Verification Program or Life Sciences Verification Program; Claude Enterprise customers can also reach it indirectly through Claude Security. It shares Fable 5.2's specifications: text and image input, text output, tool use, adaptive thinking that is always on (default effort high), a 1M-token context window, 128K max output, and June 2026 knowledge and training-data cutoffs. Pricing matches Fable 5.2 at $8/$40 per million input/output tokens, with cache reads at $0.20, 5-minute cache writes at $10 and 1-hour cache writes at $16; fast mode ($16/$80) is limited to verification-program members and is not offered on Amazon Bedrock. Anthropic calls it its most capable model for cybersecurity engineering, rediscovering 89.6% of 1,829 October 2026 CVEs versus 78.3% for Mythos 5.1. Self-reported scores (safeguards off) include Terminal-Bench 4.0 70.5%, Terminal-Bench-Science 0.1 75.3% and de novo protein binder design 85.1%. Available as `claude-mythos-5-2` on the Claude API, Claude Models on Google Cloud and Microsoft Foundry, and as `anthropic.claude-mythos-5-2` on Amazon Bedrock, where the Cyber Verification Program is currently open only to organizations with a data retention exemption for Fable 5.2 or Fable 5.1.

Model: Muse Ember
Lead: Muse Ember is a language model from Meta, released in November 2026, with multimodal input, a 1.0M-token context window, and pricing from $0.100/M input, $0.004/M cached input, $0.500/M output.
Description: Muse Ember is Meta Superintelligence Labs' smallest and most efficient multimodal reasoning model, built for high-volume agent execution such as tool calls, coding subtasks, routing, extraction, and long-document work. It is available on the Meta Model API and in Muse Code as muse-ember-1.0 in Standard mode only (there is no Contributor-mode variant). It accepts text, image, video, audio, and PDF input and returns text, with a 1,048,576-token context window and up to 524,288 output tokens. Reasoning effort ranges from minimal to max; the default is max. Pay-as-you-go pricing for requests with up to 200K input tokens is $0.10 per million input tokens, $0.004 per million cached input tokens, and $0.50 per million output tokens. Requests with more than 200K input tokens are billed in full at $0.30/$0.012/$1.50. Web search grounding costs $2.50 per 1,000 search queries on top of token charges.
