
Model: Claude Haiku 5.5
Lead: Claude Haiku 5.5 is a language model from Anthropic, released in October 2026, with multimodal input, a 1M-token context window, and pricing from $0.100/M input, $0.010/M cached input, $0.500/M output.
Description: Claude Haiku 5.5 is Anthropic's cheapest, fastest, and most capable small model to date, and the successor to Claude Haiku 4.5. It targets high-volume, cost-sensitive work (summaries, compaction, classification, database queries) and pairs with Opus 5.5 / Sonnet 5.5 as a coding subagent; it is especially strong for speed-sensitive tasks like live support and browser use. It is the first Haiku-class model with adjustable effort (low/medium/high/xhigh/max; Claude Platform default medium). It accepts text and image input (including file/PDF) with text output, supports multilingual and vision workloads, tool use, and adaptive thinking. Context window is 1M tokens with 128K max output; knowledge cutoff is June 2026. Claude Platform pricing is tiered by prompt length: prompts up to 100K tokens are $0.10/$0.50 per million input/output (cache read $0.01, 5m cache write $0.125); prompts over 100K are $0.50/$2.50 (cache read $0.05, 5m cache write $0.625). Catalog provider pricing stores the <=100K tier. Capability scores are self-reported from the Claude Haiku 5.5 System Card (Table 8.1.A and §8) and the launch announcement. Available on the Claude API as `claude-haiku-5-5`.

Model: Mistral Large 4
Lead: Mistral Large 4 is a language model from Mistral, released in October 2026, with multimodal input, a 1M-token context window, and pricing from $0.680/M input, $0.070/M cached input, $2.09/M output.
Description: Mistral Large 4 (Public Preview; aka ML4 / le Chonk) is Mistral AI's flagship general-purpose multimodal Mixture-of-Experts model. Mistral's docs describe it as 1.05T total parameters with 52B active parameters and a 1.6B vision encoder, while Mistral's Hugging Face upcoming-release page describes it as a 1T model with 49B active parameters per token (52B including embeddings and output layers). It supports a 1M-token context window with text+image input and text output, plus structured outputs, function calling, document QnA, batching, agents/conversations, and built-in tools. Launch API pricing is 50% off for two weeks versus list ($0.68/$0.07/$2.09 sale vs $1.36/$0.14/$4.18 list per million input/cached/output tokens). Weights are planned for the end of October 2026 and are not yet released, so the catalog keeps the model proprietary until a public weights license is published.

Model: GPT-6.1 Sol

Batch and Flex cost 50% of Standard; Fast costs 2x. Regional processing adds 10% where available. Launch benchmarks are OpenAI-reported; effort and evaluation variants are recorded with each score.
