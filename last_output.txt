
Model: LongCat-2.5
Lead: LongCat-2.5 is a language model from Meituan, released in November 2026, with multimodal input, a 1.0M-token context window, and pricing from $0.300/M input, $0.006/M cached input, $1.20/M output.
Description: LongCat-2.5 is Meituan's native multimodal Mixture-of-Experts model for long-horizon agentic tasks, with about 1.6T total parameters and roughly 48B activated per token. It builds on LongCat-2.0 with stronger native visual understanding and agentic coding, representing images as multi-level discrete tokens (RVQ over native-resolution features) so the backbone processes visual and text inputs in one token format. Training adds more long-horizon trajectories, large-scale asynchronous agentic RL across mixed harnesses, and multi-teacher on-policy distillation. Meituan also reports optimizing long-context training and W4A4 inference for domestic AI accelerators. The LongCat API (OpenAI, OpenAI Responses and Anthropic compatible) exposes it as LongCat-2.5 with a 1M-token context window; Meituan's Quick Start and FAQ list a 128K maximum output, while the Model Parameters page allows max_tokens up to 262,144. Launch pricing is a limited-time discount of $0.30 / $1.20 per MTok (cached input $0.006). Weights were not public at announcement.

Model: Particle-1
Lead: Particle-1 is a language model from Particle AI, released in October 2026, with multimodal input, a 1.0M-token context window, and pricing from $0.250/M input, $0.030/M cached input, $1.00/M output.
Description: Particle-1 is Particle AI's first model, a reinforcement-learning post-train of DeepSeek V4.1 Flash (rank-64 LoRA over the experts in all layers, trained with GSPO in Cascade RL stages on internal coding and data-engineering environments). It targets agentic software engineering and is tuned to solve tasks with fewer tokens: Particle reports 28.4% to 52.2% fewer output tokens and 34.4% to 51.6% lower cost per task than the base model on Terminal-Bench 2.1, ReactBench, ADE Bench, and DeepSWE 1.1, with pass@1 within the base model's confidence intervals (72.57% aggregate task pass rate vs 71.15% for DeepSeek V4.1 Flash). Text and image input, text output, reasoning with effort control, OpenAI-compatible tool calling, 1,048,576-token context and 131,072 max output tokens. Weights are not released; it is available through the Particle API and OpenRouter (particle-ai/particle-1) at $0.25 input, $0.03 cached input, and $1.00 output per million tokens (peak; off-peak 50% off, 20:30 to 04:00 America/New_York).

Model: LFM3-1.7B
Lead: LFM3-1.7B is a language model from Liquid AI, released in October 2026.
Description: LFM3-1.7B is Liquid AI's open-weight 1.73B text model for local agents and specialized applications, the text post-trained checkpoint of the LFM3 family (Oct 27, 2026). New tri-hybrid architecture: 24 layers (13 gated short convolutions, 5 sliding-window attention with 256-token window, 6 global attention), head-wise gated attention, partial RoPE, sandwich norm. Pre-trained on 22T tokens; 256K context; 128K vocabulary; 16 languages. License: LFM Open License v1.0. Catalog benches are self-reported from the vendor table.
